Student Management System

About the Project

The Student Management System is a web-based application developed using Python and Flask. It helps manage student information in an organized way.

Features

- User Registration and Login
- Dashboard
- Add Student
- View Student Details
- Search Students
- Filter Students
- Edit Student Details
- Delete Student Details
- SQLite Database

Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

How to Run

1. Install Python.
2. Install Flask:

pip install flask

3. Open the project folder in VS Code.
4. Run:

python app.py

5. Open the local URL shown in the terminal.

Database

The project uses SQLite to store user and student information.

Conclusion

This project provides a simple and user-friendly way to manage student records using a Flask web application.
